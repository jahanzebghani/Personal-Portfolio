Jahanzeb Portfolio - React + Vite + Tailwind + Framer Motion

How to run:
1. cd jahanzeb-portfolio
2. npm install
3. npm run dev
Open http://localhost:5173

Notes:
- The resume and profile image are inside the public/ folder (jahanzebjobcv.pdf and profile.jpg).
- Customize text in src/App.jsx
- To wire the contact form, use EmailJS, Formspree, or a backend endpoint.
